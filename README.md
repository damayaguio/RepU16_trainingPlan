# RepU16 Kitchener – Winter Training Plan

Static website for the 20-week winter training block (Nov 7, 2026 – Mar 20, 2027).

- `index.html` – the site (open it in a browser, or publish with GitHub Pages)
- `assets/data.js` – all session content and video links
- `assets/anim.js` – drill animations (Weeks 2–5)
- `assets/app.js`, `assets/style.css` – navigation and layout
- `diagrams/` – static drill diagrams

No build step is needed. Edit `assets/data.js` to change session text, then commit.
